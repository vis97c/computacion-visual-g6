# Computación Visual

Ejercicios del curso de computación visual

## Estructura del proyecto

- `semana_2_1_espacios_proyectivos_matrices_proyeccion`: Ejercicios de la semana 2, lección 1
- `semana_2_2_proyecciones_camara_virtual`: Ejercicios de la semana 2, lección 2
- `semana_2_3_camara_pinhole_calibracion`: Ejercicios de la semana 2, lección 3
- `semana_2_4_transformaciones_homogeneas`: Ejercicios de la semana 2, lección 4

Ejecutar un proyecto:

```bash
yarn workspace semana-2-1 run dev
```

Los otros archivos son de configuración del proyecto (Linters, formatters, etc.)
